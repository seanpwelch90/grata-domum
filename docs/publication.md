# Public snapshot

This repository starts from a clean export of the current Grata Domum implementation, including native onboarding and Bonjour discovery. Historical private Git commits, conversations, reference images and household databases are not published.

The public app uses the project’s original native Canvas house and matching original web SVGs. Raw Storyset illustration files are omitted because their license does not authorize redistribution in a source repository. Fonts include their original OFL notices. The accepted solid-color cards and locally bundled typography are retained.

The original development checkout and its artwork/history were preserved separately. This public checkout is the place to make future publicly shareable changes; reviewing privacy and asset rights remains necessary before importing further private work.
